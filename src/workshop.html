CI/CD Workshop Manual

Build a personal website and deploy it automatically with GitHub Actions.

🎯 Overview

In this workshop, you will:

  • Build a simple personal website (HTML, CSS, JavaScript)
  • Push it to GitHub
  • Write a CI/CD pipeline using GitHub Actions
  • Watch it automatically test, build, and deploy to a live URL

By the end, you'll have:

  • A live website at https://YOUR-USERNAME.github.io/website-demo/
  • A working CI/CD pipeline triggered on every push
  • Real experience with the tools professional developers use
💡 What is CI/CD? CI (Continuous Integration) = Every time you push code, tests run automatically.
CD (Continuous Deployment) = If tests pass, your code is deployed automatically.

🚀 Part 1: Setup

1Create a Repository on GitHub

  1. Go to github.com/new
  2. Repository name: website-demo
  3. Description: My personal website with CI/CD
  4. Visibility: Public
  5. Check ✅ Add a README file
  6. Click "Create repository"

2Clone It Locally

Open your terminal and run:

Terminal
cd ~/Desktop
git clone https://github.com/YOUR-USERNAME/website-demo.git
cd website-demo

Replace YOUR-USERNAME with your actual GitHub username.

Purpose: git clone downloads the repo to your computer so you can edit it locally.

3Configure Git (One-Time)

Terminal
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
⚠️ Use your GitHub email The email must match an email on your GitHub account. Find it at github.com/settings/emails. Otherwise, your commits won't appear on your profile.

Verify:

Terminal
git config --list

⚙️ Part 4: Create the CI/CD Pipeline

1Enable GitHub Pages (Critical!)

🚨 Do this BEFORE running the workflow If you skip this, your deploy job will fail with "Get Pages site failed. Not Found".
  1. Go to your repository on GitHub
  2. Click Settings (top menu)
  3. Left sidebar → Pages
  4. Under Build and deployment → Source: choose "GitHub Actions"
  5. No branch selection needed — just pick "GitHub Actions" from the dropdown
💡 Why this step? GitHub Pages has two modes: "Deploy from a branch" (legacy) and "GitHub Actions" (modern). Our workflow uses the modern mode. Without selecting it, GitHub doesn't know to expect a workflow deployment.

2Create the Workflow File

Terminal
mkdir -p .github/workflows
nano .github/workflows/deploy.yml
.github/workflows/deploy.yml
name: 🚀 Build and Deploy Website

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  # ══════════════════════════════════════════════
  # JOB 1: TEST — Validate the website
  # ══════════════════════════════════════════════
  test:
    name: 🧪 Test
    runs-on: ubuntu-latest
    steps:
      - name: 📥 Checkout code
        uses: actions/checkout@v4

      - name: ✅ Verify required files exist
        run: |
          echo "Checking for required files..."
          test -f src/index.html || (echo "❌ src/index.html missing" && exit 1)
          test -f src/style.css  || (echo "❌ src/style.css missing" && exit 1)
          test -f src/script.js  || (echo "❌ src/script.js missing" && exit 1)
          echo "✅ All required files present!"

      - name: 🔍 Validate HTML structure
        run: |
          echo "Validating HTML..."
          grep -q "" src/index.html || (echo "❌ Missing DOCTYPE" && exit 1)
          grep -q " tag" && exit 1)
          grep -q "" src/index.html    || (echo "❌ Missing " && exit 1)
          grep -q "" src/index.html    || (echo "❌ Missing " && exit 1)
          echo "✅ HTML structure is valid!"

  # ══════════════════════════════════════════════
  # JOB 2: BUILD — Package the site
  # ══════════════════════════════════════════════
  build:
    name: 🏗️ Build
    runs-on: ubuntu-latest
    needs: test
    steps:
      - name: 📥 Checkout code
        uses: actions/checkout@v4

      - name: 📁 Create build directory
        run: |
          mkdir -p dist
          cp -r src/* dist/
          echo "Build complete!"

      - name: 📝 Add build info file
        run: |
          echo "Build Date: $(date -u)" > dist/build-info.txt
          echo "Commit SHA: ${{ github.sha }}" >> dist/build-info.txt
          echo "Branch: ${{ github.ref_name }}" >> dist/build-info.txt
          echo "Triggered by: ${{ github.actor }}" >> dist/build-info.txt

      - name: 📤 Upload build artifact
        uses: actions/upload-artifact@v4
        with:
          name: website-build
          path: dist/
          retention-days: 7

  # ══════════════════════════════════════════════
  # JOB 3: DEPLOY — Publish to GitHub Pages
  # ══════════════════════════════════════════════
  deploy:
    name: 🚀 Deploy
    runs-on: ubuntu-latest
    needs: build
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: 📥 Checkout code
        uses: actions/checkout@v4

      - name: 📁 Prepare site files
        run: |
          mkdir -p _site
          cp -r src/* _site/
          echo "Site ready for deployment"

      - name: 🔧 Configure GitHub Pages
